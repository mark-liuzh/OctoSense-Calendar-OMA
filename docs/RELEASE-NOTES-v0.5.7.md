## 一、用户可见修复

### 1. 事件详情面板 tab 「点了没反应」（真人实测复现）

用户报告：详情页五个 tab 中「笔记/纪要」点击无反应，「跟进/链接/历史」有反应。两个叠加根因：

- **布局溢出**：`sync_panels()` 的日历让位规则漏了详情 / AI 排程 / 周报面板。日视图下头部 + 日历 + 工具条已占 761px，849px 窗口里详情面板只剩 88px 可见，tab 内容全部在屏幕外；高度不变的 tab（笔记↔纪要）看起来「没反应」，高度变化的（Fit 内容）才有反应。修复：这三个面板打开时日历自动让位。
- **TextInput 显隐空操作**：makepad `Widget::set_visible` 默认实现为空且 `text_input.rs` 未覆写，对输入框 `set_visible` 是静默无效操作 —— 笔记/纪要两个输入框永远同时占位。修复：各包一层 View 外壳切换显隐。

### 2. 目标卡长标题挤出按钮（v0.5.6 评审反馈）

目标卡片标题独占一行并允许换行，进度、期限与操作按钮固定在独立行内，长标题不再把按钮推出视口。

### 3. 待办转日程（auto 事件）重排正确性

- 排期时显式写入 `start_minutes` / `end_minutes`，60 分钟待办不再被 rebalance 错误按 30 分钟重排；
- `rebalance_auto_events` 对数字字段不再调字符串方法（跨天时长兜底正确）；
- 「事件详情」默认打开**当天第一个活跃事件**（跳过已取消的）；
- 取消阻塞事件后 auto 事件正确前移到空档。

## 二、测试与工具链

- **P2-5 新功能 e2e 固化**：历史回滚 + 取消后自动释放合并场景 18 项断言（数据层 + UI 闭环）；修复驱动侧「今天」与应用进程日期对齐（跨零点不再连锁崩）。
- e2e 灌入预算随内容长度缩放、连续 3 次读到位才收敛（修死循环/超时）。
- `HOST_ERROR_WHITELIST` 正则失配修复；`shellsafe` 自检 `${VAR:-$VAR}` 自引用；节日/布局/新功能驱动脚本修复。
- macOS 串行全量回归 9/9 PASS（静态门禁 13 道 + e2e / conflict / edge / negative / festival / layout / new / features / new_features）。

## 三、已知限制

- 详情页 tab 行的**宿主合成点击**存在 capture 缺陷（hover 100% 命中、click 到达 VM 概率 ~6%，9 方案穷举无效）——真人鼠标不受影响；e2e 已用数据层断言兜底。
- 详情 / AI 排程 / 周报面板打开时日历让位（与导入面板同一套路），关闭后面板原样恢复。
